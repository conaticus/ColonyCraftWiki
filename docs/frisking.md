# Frisking

Using the `/frisk` command, you can request to search other players. This allows you to take any items from a player's inventory, as well as put items inside it.

To frisk someone, you must be within one block of the other player, and when in frisking mode, the player being frisked will not be able to interact with their inventory until you are done frisking them.

Usage: `/frisk <player>`
