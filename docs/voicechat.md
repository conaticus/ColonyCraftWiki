# Voice Chat Setup

While Voice Chat is optional, it greatly enhances the immersive experience of Colony Craft.

### Installation

1. Install Fabric Installer for Your Minecraft Version: [https://fabricmc.net/use/installer/](https://fabricmc.net/use/installer/)
2. Run the Fabric Installer
3. Install Simple Voice Chat for Fabric: [https://modrinth.com/plugin/simple-voice-chat](https://modrinth.com/plugin/simple-voice-chat)
4. If on Windows, type Win+R (or open Run) and type `%appdata%/.minecraft/mods`
   (_for Mac and Linux go to `[minecraft installation directory]/mods`_)
5. Paste the Simple Voice Chat JAR into the Directory
6. Run the Minecraft Launcher and Ensure to Select the Fabric Loader
7. When joining the server, press "V" and setup your microphone (you can press V at any time to open the voice chat menu)
