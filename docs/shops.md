# Shops
Shops in Colony Craft allow players to sell items that they have gathered for a chosen price. This is a core part of Colony Craft and has been designed to be as flexible as realistically possible. This enables immersive politics and simulation of economic concepts such as inflation or supply and demand - the creativity is up to the players!

### Creating a Shop
Each chest can hold one shop. To create multiple shops with different prices and items you must repeat the process below.

Any player can create a shop by:
- Placing a single or double chest on their [claimed land](/docs/claims/claims.md)
- Using the command `/shop create <selling item> <selling amount> <price item> <price amount>`.
- Right clicking the chest (which assigns the shop to that chest)

### Deleting a Shop
Deleting a shop is very simple, you must break the whole chest and the profits and stock will drop along with it.
