# Raiding Colonies

It is highly recommended that you read the following guides before this one:

- [Colonies](/docs/colonies/colonies.md)
- [Raiding Bases](/docs/raids.md)

Raiding a colony works slightly differently to raiding bases in Colony Craft. Each colony has a Colony Core that is usually hidden and protected by the colony leader. This can be destroyed with a powerful raid ([See Recipe Here](/docs/recipes/raid-pickaxes.md#powerful-raid-pickaxe)).

When a Colony Core is damaged, this damage is remembered until the Colony Members repair the Colony Core in their community chest. When a Colony Core is destroyed, the colony will be deleted and all its controlled land will be lost.
