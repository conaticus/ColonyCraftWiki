# Enchanting

Enchantment tables can be crafted & used in the same way as vanilla Minecraft, however there are some things to know about the enchantments available to you.

### Using an Enchanting Table

Firstly, to craft an enchantment table, this requires [Engineer](/docs/skills/engineer.md) Level 2. However, once crafted, any player at any skill level can use an enchantment table.

Note that for balancing purposes, we have decreased the amount of lapis that drops to just **one** Lapis Lazuli per Lapis Ore.

### Unlocking Enchantments

#### Skill Requirements

All enchantments except for Unbreaking are by default unavailable to players. There are a number of enchantments, however, that can be unlocked when progressing a skill. Refer to the levels sections in the [skill summaries](/docs/category/skills) to find the enchantments available.

#### Book Requirements

To adhere to Minecraft's Enchanting system, enchantments also require books to be placed around an enchantment table for better levels & more obtainable enchantments. These will be required in addition to the skill level required for each enchantment.

### Maximum Enchantment Levels

To avoid players becoming too overpowered, we have also placed some restrictions to the enchantment levels available. For example, Knockback II is now the maximum obtainable Knockback level. Anvils also enforce this restriction - so don't bother trying ;)

Below is a table addressing the maximum enchantment levels for each enchantment. **Any unlockable enchantments that are not listed have no restriction on their level.**

| **Enchantment** | **Maximum Level** |
| :-------------: | :---------------: |
|    Knockback    |         2         |
|      Power      |         2         |
|      Punch      |         2         |
|   Protection    |         2         |
|    Sharpness    |         2         |
