# Colony Chat

Once you are in a colony, you can opt into the colony chat which will only broadcast your messages to members of your colony.

To send messages in the colony chat only, run the `/chatmode colony` command (or with alias `/c colony`). When in this mode, you will still receive messages from global chat.

To send messages again in global chat, run `/chatmode global` or `/c global`.
